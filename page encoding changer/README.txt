Chrome Extension: Page Encoding Changer
========================================

This extension allows you to force change the character encoding of any webpage.

Features:
- Quick access to 16 common encodings (UTF-8, GBK, Shift_JIS, etc.)
- Custom encoding input for rare encodings
- Dark mode support
- Saves encoding preference per URL

How to Install:
1. Open Chrome and go to chrome://extensions/
2. Enable "Developer mode" in the top right
3. Click "Load unpacked"
4. Select this folder: E:\0programing\chrome extensions\page encoding changer

How to Generate the Icon:
- Open generate-icon.html in your browser, it will auto-download icon.png
- OR create a 128x128 PNG icon manually and save it as icon.png in this folder
- OR use the SVG file (icon.svg) and convert it to PNG using any online converter

How to Use:
1. Click the extension icon in the toolbar
2. Select an encoding from the grid
3. The page will reload with the new encoding
4. Use "Reset to Original" to restore the page
